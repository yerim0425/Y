# 편집 스타일 가이드 (레퍼런스 영상 3개 분석)

레퍼런스: 대구 카페/맛집 브이로그(55.8s), 리스본 가을 스커트 룩(33.9s), 목욕템 5가지(49.9s)

## 포맷
- 세로 9:16, 720x1280 (원본이 더 크면 1080x1920도 가능), 30fps, H.264 + AAC 44.1kHz 스테레오
- 길이 30~60초 (쇼츠/릴스)
- 오디오 평균 음량 약 -16.5 dB, 피크 -1 dB → 라우드니스 노멀라이즈 (약 -14 LUFS)
- 무음 구간 없음: 보이스오버(내레이션)가 처음부터 끝까지 이어지고, 배경음악이 깔림

## 컷 편집
- 빠른 템포: 평균 컷 길이 약 1~1.2초 (정보형/루틴 영상은 2초 내외)
- 첫 프레임부터 바로 본론. 인트로 없음
- 내레이션 한 구절 = 한 컷 단위로 맞춰 자름
- 같은 장소에서 여러 앵글(전신 → 디테일 → 손/음식 클로즈업) 교차
- 마무리는 짧은 결론 멘트 컷 (예: "삶의 질 확 올라갑니다")

## 자막
- 일반 자막: 작은 흰색 고딕(산세리프), 얇은 그림자/외곽선, 화면 정중앙~중앙 약간 아래 (세로 약 45~50% 위치)
- 한 번에 짧은 한 구절만 (10자 내외), 내레이션과 정확히 싱크
- 강조 멘트(예: "미쳤죠")는 같은 위치에 더 크게
- 배경/의상에 따라 흰 글씨가 묻히면 그림자 강화

## 타이틀 (훅)
- 영상 첫 1~4초에 크게 2줄 타이틀, 화면 중앙
  - 예: "효과는 너무 좋은 / 레전드 목욕템 5가지", "26년도 가을신상 / 스커트 보물찾기🔍"
- 흰색 큰 글씨 + 검은 외곽선, 손글씨/세리프 느낌 폰트
- 숫자, 연도, "레전드" 같은 훅 키워드 사용

## 장소 / 정보 태그
- 장소 소개 시: 📍 + 굵은 흰색 장소명 (예: "📍스튜디오 콩", "📍언더스탠드업"), 그 아래 작은 설명 한 줄
- 주소는 화면 상단에 작게 (예: "📍대구 중구 대봉동 17-5")
- 제품 소개 시 구매내역/제품 스크린샷 캡처를 작게 오버레이

## 톤
- 차분하고 감성적인 일상 브이로그, 컬러 보정은 자연스럽게(따뜻한 톤 약간)
